# IET supplementary data tables

These files are the supplementary tables referenced in the revised manuscript `副本IET1711_实验数据补强版_20261001.docx`.

- `Supplementary_Table_S1_formal_run_metrics.csv`: per-run metrics for all 35 selected formal samples.
- `Supplementary_Table_S2_excluded_attempts.csv`: the three retained attempts excluded from formal performance statistics.

The CSV values are copied from the frozen final-run index and selection manifest. Raw logs and full configuration evidence remain in the corresponding run directories under `03_正式闭环35样本` and `04_未纳入统计的尝试`.
