# 实测反馈改造与执行动态复测交付

## 结论

工程已改动并实际运行，不是仅给方案。多旋翼每轮 NMPC 使用逐机实测位置与航向；固定翼以平台相关航迹制导、目标空速及高度指令接入 ArduPlane。S1、S2、S3 均有完整航线及退出记录，位置跟踪达标。

**但固定能力边界下的实际动态约束没有全部通过，当前不能交付为“论文全部实验成功”。** 本阶段7次开发飞行中6次完整跟踪通过，1次预测序列试验失败；只有12 m/s直线运行同时通过本次遥测约束检查，正式资格为0次。没有抬高能力界、增加容差、平滑掉越界样本或删除失败记录。

更早的 `formal_v3` 是旧反馈/执行版本的历史数据，不能用来证明新实测反馈闭环。它仍完整保留。本轮不能继承该批次的重复性或能力标定结论。

- 多旋翼：上游 ArduCopter `x:freestyle.json`，`freestyle.parm`；固定翼：通用 ArduPlane `plane`，`plane.parm`。不是商品机型或实机验证。
- 飞控4.8.0-dev，提交 `a82481310ba19fe013e4797ea05cf702e76836bb`；实际二进制哈希、完整命令、参数快照在每机 `manifest.json` 和 `defaults.parm`。
- 无风、相对高度60 m、固定横向槽位；S1/S2三机槽位为-10/0/+10 m，S3为两架多旋翼和一架固定翼，固定翼槽位+10 m，先左转内侧、后右转外侧。
- 新后端的能力证据标记仍为 `prior_backend_calibration_pending_revalidation`。原冻结值为多旋翼速度0–20 m/s、横向加速度3 m/s²、偏航角速度0.25 rad/s、切向加速度±0.4 m/s²；固定翼空速12–24 m/s、滚转角27°、横向加速度2.5 m/s²、切向加速度±0.2 m/s²。这些是本轮不可放宽的验收边界，不宣称已在新后端重新标定。
- 固定翼滚转角速度上限未知，未填猜测值。多旋翼后飞、左右飞的当前后端能力未重新标定。前飞12、14 m/s只是两个直线实测点，不等于连续0–20 m/s包线证明。
- 无风下按配置计算的直线共同区间为 `[max(0,12), min(20,24)]=[12,20] m/s`。固定翼使用空速检查下限，多旋翼使用实测地速；上述区间是配置门槛，不是当前组合的完整实测能力区间。

原ROS链仍保留：`DroneMPC -> PositionCommand -> poscmd_bridge -> MAVROS PoseStamped -> ArduCopter`，只转发位置和航向。该链的先前跟踪复测未通过，不以本轮直接MAVLink数据替它验收。

本轮运行入口 `scripts/run_paper_sitl.py` 使用独立的直接MAVLink位置/速度/加速度/yaw/yaw_rate后端；`--copter-synchronous` 将这些设定点对齐到同一发送时刻。此选项必须显式启用，未改变原ROS位置桥默认行为。速度/加速度前馈不意味着实际速度或加速度被硬约束。

实测反馈模块处理世界系变换、±pi跨界、消息过期/缺失和两流时间对齐；直接入口允许最大0.2 s短测量外推，年龄上限0.5 s。实际每次X0、实测输入、控制、状态、时间戳和失败计数均存入 `feedback_solves.jsonl`。ROS共同实测时间插值和直接入口两流短外推的实现不同，详见前一阶段反馈改造报告。

### 超限证据

- S1 reserved各机实际yaw越界时间占比约1.30%、1.89%、1.67%；加长过渡的S1 smooth反而约10.69%、9.00%、8.91%。不能宣称增大半径或加长过渡必然改善执行动态。
- S2 reserved成员2负、正切向加速度越界约18.95%、20.53%。同一时钟窗口SIM2真值范围为-0.962至0.754 m/s²，真值越界占比约22.36%、22.98%，证据在 `s2_reserved_truth_m2/`。这不能只归因为遥测差分噪声。
- S2 matched slew成员2的负、正越界比例降至约8.55%、9.80%，但其他成员部分指标变差，且位置误差增大。只能说单次调整改变了误差/动态违反的折中，不能声称已解决或普遍更优。
- S3 smooth固定翼负、正切向越界约18.76%、18.30%；两架多旋翼yaw越界约11.58%、9.08%。

主指标始终从原始时间戳唯一采样差分计算，不做平滑。诊断真值是独立解释证据，不替换主验收算法。
